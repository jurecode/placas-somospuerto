Token de GitHub

El repositorio es privado, así que para bajar la versión hace falta un token. En GitHub → Settings → Developer settings → Fine-grained tokens, con permiso Contents: read sobre placas-somospuerto y nada más. Queda en la base, igual que el de Instagram.

Baja el zip de la última versión publicada y lo descomprime encima. Nunca toca api/config.php, así que tus credenciales quedan donde están.

Cómo se configura

  1. En Instagram, la cuenta tiene que ser Profesional (Empresa o Creador) y estar vinculada a una página de Facebook.
  2. En developers.facebook.com creá una app, agregá el producto Instagram y generá un token de larga duración con los permisos instagram_business_basic e instagram_business_content_publish. Ahí mismo aparece el id de la cuenta.
  3. En cPanel creá una base MySQL y un usuario con permiso sobre ella. Las tablas se crean solas la primera vez; después las podés mirar desde phpMyAdmin.
  4. Copiá api/config.ejemplo.php como api/config.php y completá los datos de la base más PUBLICAR_CLAVE.
  5. Dale permiso de escritura (755) a las carpetas fotos/ y publicaciones/.
  6. Volvé acá, cargá el id y el token de Instagram, y revisá que quede todo en verde.

Lo único que se escribe a mano en el servidor son los datos de la base y la clave, en api/config.php — archivo que no está en GitHub ni se sirve por web. El token de Instagram sí se guarda desde acá, porque vence cada 60 días y tenerlo en la base evita entrar por FTP cada vez.

El token de larga duración vence a los 60 días. Si un día deja de publicar, es lo primero que hay que revisar acá.
